# Partial Image Encryption using DCT

This is my course project for the Foundations of Cryptography course. The research topic focuses on partial image encryption by applying Discrete Cosine Transform (DCT).

## Project Overview

The project consists of two main parts (for educational purposes):

1. **Encryption**:
   - Encryption with a key
   - Steganography *(in development)*

2. **Recovery Attempts**:
   - Attempting to recover encrypted images without any prior information
